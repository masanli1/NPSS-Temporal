# NPSS-Temporal

作者：[masanli1](https://github.com/masanli1) · 仓库：[NPSS-Burst](https://github.com/masanli1/NPSS-Burst)

[English](README.md)

> **沿时间序列连续降噪：每一帧都用它前后帧来补足。**
> 连续帧是互补的：内容相同、噪声独立。对齐后平均，噪声按 √N 下降，细节保留——
> 这是任何单帧降噪都做不到的。

核心纯 numpy，只有从视频取帧时才需要 ffmpeg。

## 流程

来自 NPSS-Enhancer 的 `GUI/traj_denoise.py`（轨迹累积）：

```
N 张连续帧
  ↓  帧间块匹配光流（由粗到精金字塔）
  ↓  沿轨迹链路累积，把每帧 warp 到目标帧
  ↓  鲁棒加权合并（中位数参考 → 高斯权重）
  ↓  可选：对合并结果再做一遍单帧降噪
一张干净照片
```

### 修掉的三个 bug（相对原实现）

| bug | 后果 | 修法 |
|---|---|---|
| 光流只在 1/4 分辨率上算 | **1–2 像素的抖动完全测不出**（实测 Δ=0.00 px） | 增加全分辨率一级；粗到精金字塔同时覆盖 ±24 px 和亚像素 |
| 平坦块锁定到第一个搜索偏移 | 无纹理块在任何偏移下误差都是 0（孔径问题），于是 −R 胜出并抹遍全图——**零位移**的一对帧测出 **−4.65 px** | 方差判据剔除平坦块，再从有效邻域填补流场 |
| 块误差未按重叠面积归一化 | 边界块没有重叠区域，评分没有意义 | 误差除以有效重叠像素数 |

无噪声整数裁剪的配准质量：

| 真位移 | 修之前 | 修之后 |
|---|---|---|
| 0 像素 | 34.16 dB（流 −4.65 px） | **108.00 dB**（流 0.00 px） |
| 1 像素 | 33.47 dB | **39.58 dB** |
| 3,−2 像素 | 33.79 dB | **36.81 dB** |

## 关于数字的诚实说明

`benchmark.py` 用重采样和整数裁剪两种方式合成连拍，**都复现不出 40 dB 的融合结果**：

- 重采样出来的帧本身被插值糊过，上限约 31 dB，融多少帧都一样；
- 1/f 随机纹理在不同裁剪位置内容不同，平均不同内容并不等于同一个信号。

NPSS-Enhancer 历史里记录的那个 **40.66 dB（静态区）** 是**真实拍摄素材**跑出来的——真实帧没有插值模糊。
要复现它得用真实视频，这个合成基准替代不了。

## 实测

## 真实素材实测

iPhone 静物片段，1088×1440，28.5 fps，24 帧，手持漂移 ±15 像素，噪声 σ ≈ 1.7/255：

| | 单帧 | `denoise_sequence(radius=3)` |
|---|---|---|
| 噪声 σ | 1.72 | **1.42**（−17%） |
| 逐帧降幅 | — | 12% … 23% |

肉眼看，「净含量 500ML」小字和瓶身上的金色颗粒从糊在一起变成可分辨。
代价：1088×1440 下 **4.8 秒/帧**（光流占大头）。

为什么只降 17%、而不是 √9 暗示的 67%：镜头在 1.9 秒内漂了约 15 像素，
配准残余把平均效果吃掉大半。

## 合成连拍实测

`python3 benchmark.py`：384×384 纹理场景，每帧随机位移 ≤ ±2 像素，AWGN σ=20。

| 帧数 | 单帧带噪 | 单帧降噪 | 直接平均 | **对齐融合** | 理想配准 |
|---|---|---|---|---|---|
| 4 | 21.34 | 24.60 | 23.89 | **25.57**（+0.97） | 26.90 |
| 8 | 19.02 | 22.71 | 23.25 | **23.00**（+0.29） | 27.17 |

「理想配准」用的是已知位移，所以它与对齐融合的差就是**配准误差的代价**：
4 帧 1.3 dB，8 帧 4.2 dB。

### 老实说

- 这组合成数据上，融合只比单帧降噪高 **0.3~1.0 dB**，8 帧时还不再提升——残余错位把平均糊掉了。
- 如果配准是准的，同样的帧能拿到 **+2.5~4.5 dB**。
  **瓶颈是配准精度，不是融合思路本身。**
- 真实手持连拍的运动比这组测试更小更平滑，效果应当介于两列之间，但**这一点没有实测**。

## 用法

```python
import numpy as np
from PIL import Image
import npss_burst as B

frames = np.stack([np.asarray(Image.open(f).convert("RGB"), np.float32) / 255.0
                   for f in sorted(paths)])
out, info = B.fuse(frames)
Image.fromarray((out * 255 + 0.5).astype(np.uint8)).save("clean.png")
```

命令行：

```bash
python3 demo.py --video clip.mp4 --time 3.0
python3 demo.py --frames burst/
python3 benchmark.py --frames 4 8 16 --sigma 20 50
```

## 它不是什么

- **不是多帧超分**：融合后的分辨率等于输入帧的分辨率。
- **不是视频降噪**：只从一小段连拍里出一张静帧，不做整段视频的时域滤波。
- **不是免配准的**：帧间位移超过几个像素，仿射模型就失效，融合会退化到单帧效果。
